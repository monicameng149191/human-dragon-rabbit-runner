# 人龍兔向前衝 | Dragon Rabbit Runner

An offline, single-file browser runner game. Choose a character and terrain, then jump and crouch to dodge obstacles. The game also includes hidden Moon and Underwater Ruins stages.

## Play

Open [`index.html`](index.html) in a modern browser. The game runs locally and does not require a network connection.

## Controls

- **Jump:** `↑`, `Space`, or the on-screen Jump button
- **Crouch:** `↓` or the on-screen Crouch button
- **Moon booster:** press Jump again while airborne

## Source

The complete game is in `index.html`; it uses Canvas and has no external runtime dependencies.
